What is HTML-in-Canvas?

Chrome's HTML-in-Canvas API lets a page draw live DOM elements into a WebGL or WebGPU texture while the elements keep working: focus, text input, selection, find-in-page and the accessibility tree all behave like a normal web page. Unity composites the texture; the browser owns layout and input.
